# Windows UI 完成条件与验收标准

> 本文件定义 Windows 视频播放器 UI 的完成门槛。UI 源码已实现、控件已出现或文档已勾选，都不等于 UI 完成。只有代码审查、Windows 构建和下列运行验收全部通过，才允许将 Windows UI 标记为完成。
>
> 开发分支：`gptdev`。不直接提交 `main`；不自动运行 CI。

## 1. 范围与产品原则

### 本阶段范围

- Windows 桌面视频播放器，Qt 6 Widgets。
- 单窗口单进程、每进程一个 Player；多个窗口可独立启动和退出。
- 视频文件打开、播放控制、画面呈现、播放队列、字幕、视频内音轨选择、截图、播放信息、视频设置和 Windows 文件关联。
- PotPlayer 作为交互行为参考；采用现代、简洁、统一的深色 UI，不复制其过时视觉样式。
- 应用配置和数据优先位于程序目录 `Data/`，配置文件为 `Data/settings.ini`；仅在程序目录不可写时回退到当前用户专属 Local App Data。
- Core 不依赖 Qt 或 Windows UI；UI 通过 C ABI 与 Core 通信。

### 明确不在本阶段范围

- 独立音乐播放器、音乐库和音频文件播放模式。
- Android UI、多端同步、远程控制、P2P。
- GPU 拔出、驱动重置、多显卡切换等设备故障恢复高级功能。
- 尚无真实数据来源的 GPU 使用率、丢帧率等性能仪表。
- 不得为了完成 UI 而把 Qt/UI 类型引入 Core。

视频文件中的音轨选择属于视频播放的轨道控制，不代表扩展为通用音频播放器。

## 2. 完成门槛（Definition of Done）

以下各项必须全部满足：

1. **功能闭环**：每个可见按钮、菜单项、快捷键、手势和设置项都连接真实命令；没有空操作、假状态或只改变控件外观的伪实现。
2. **命令一致性**：同一命令从工具栏、菜单、右键菜单、快捷键或手势触发，调用相同业务入口，结果和状态同步。
3. **状态正确性**：空闲、打开中、播放、暂停、Seek、停止、EOF、失败、无视频流和关闭状态均正确显示；媒体切换不残留旧标题、时长、进度、字幕、帧或错误。
4. **异步正确性**：耗时操作不阻塞 GUI 线程；旧媒体/旧 Seek 的过期结果不得覆盖当前媒体；窗口关闭时先终止并排空 UI 异步任务，再销毁 Player。
5. **持久化正确性**：设置、窗口布局、播放队列/最近播放、媒体播放位置和书签按定义写入 INI；重启后恢复；取消设置不落盘；恢复默认范围明确。
6. **输入正确性**：键盘焦点、文本输入、列表导航、快捷键录入、菜单弹出期间不被全局播放器快捷键抢占。
7. **视觉一致性**：字体、图标、间距、控件高度、圆角、颜色、禁用/悬停/按下/选中状态有统一规范；无文字截断、控件重叠和不必要的系统原生风格混杂。
8. **窗口适配**：普通/最大化/全屏、窗口缩放、多显示器、高 DPI、显示器拔插后的窗口恢复可用。
9. **故障可理解**：文件打不开、格式/编码不支持、字幕加载失败、截图失败等情况给出用户可理解的原因和恢复入口，不显示无意义的内部错误码。
10. **真实验收**：Windows x64 MSVC + Qt 的 Debug/Release 至少完成一次构建和运行；发布包在干净 Windows 环境启动。文档、静态检查和 Linux 构建不能替代 Windows 验收。

任何 P0 验收项失败，整体 UI 不得标记完成。

## 3. 交互与功能验收矩阵

### A. 主窗口与画布

- [ ] A01 首次启动显示清晰的打开文件/拖放提示，不显示空白黑窗或误导性播放状态。
- [ ] A02 打开媒体后，标题、路径提示、视频尺寸/时长、播放状态与当前媒体一致。
- [ ] A03 打开期间有加载反馈；首帧真正呈现后才结束加载状态。
- [ ] A04 损坏文件、无视频流、解码器不支持、文件不存在时显示可理解错误；失败后可继续打开其他文件。
- [ ] A05 切换媒体、清空队列、关闭媒体后，旧帧、旧字幕、旧进度、旧错误和旧元数据不残留。
- [ ] A06 窗口标题和播放信息不因异步完成顺序而回退到旧媒体。

### B. 播放控制与时间轴

- [ ] B01 播放、暂停、停止、关闭、上一项、下一项操作正确，菜单/工具栏/快捷键状态同步。
- [ ] B02 进度条支持点击定位和拖动定位；拖动期间显示目标时间，释放后执行 Seek。代码已实现点击轨道直接跳转及拖动定位，仍需 Windows 运行验证。
- [ ] B03 连续拖动/快速 Seek 时只呈现最新目标结果，旧帧不得闪回。
- [ ] B04 当前时间、总时长、进度条、逐帧位置一致；暂停时不继续增长。
- [ ] B05 EOF 按普通播放、单项循环、列表循环和自动下一项设置执行正确。
- [ ] B06 播放速度支持设置范围，UI 显示真实 Core 生效速度；切换速度不产生明显时间跳变。
- [ ] B07 逐帧前进/后退在暂停状态下工作；边界处不崩溃、不显示其他媒体的历史帧。
- [ ] B08 A-B 循环设置、清除、B 不大于 A 的错误提示和跨 Seek 行为正确。
- [ ] B09 OSD 对音量/静音（若视频音轨启用）、Seek、倍速、截图、轨道、字幕和画面调整等可见命令提供一致反馈；不遮挡必要操作。
- [ ] B10 时间轴悬停时间提示准确；若实现缩略图预览，必须异步、去抖、限制解码开销并丢弃过期结果。缩略图预览不是 UI 完成的强制前置项。

### C. 播放列表与媒体管理

- [ ] C01 支持打开单文件、多文件、文件夹、命令行路径和文件管理器拖放。
- [ ] C02 支持队列添加、播放指定项、移除单项、多选批量移除、清空、排序/拖动调整顺序。
- [ ] C03 当前播放项有明确选中/播放标识；播放队列和独立队列窗口状态同步。
- [ ] C04 文件名、时长、分辨率列与实际媒体一致；元数据尚未读取时显示合理占位状态。
- [ ] C05 右键菜单操作作用于点击项或当前选择项，批量操作边界正确。
- [ ] C06 删除当前项、删除前后项、清空队列时，当前媒体与索引行为正确，不误播错误项目。
- [ ] C07 最近播放列表可重新打开文件；文件已不存在时有明确处理，不崩溃。
- [ ] C08 队列持久化和恢复后顺序、当前媒体、播放位置语义正确。
- [ ] C09 队列侧栏显隐偏好与全屏自动隐藏临时状态分离；临时隐藏不能覆盖用户偏好。

### D. 菜单、右键与鼠标交互

- [ ] D01 顶层菜单按文件/播放/视频/字幕/音轨/窗口/帮助等功能组织，常用命令可发现。
- [ ] D02 视频画布右键菜单包含高频操作，菜单内容随媒体状态启用/禁用。
- [ ] D03 播放列表右键菜单支持添加文件、播放、移除、上移、下移、清空和打开播放器设置等与点击项/选择状态匹配的操作。
- [ ] D04 中键默认切换全屏；可配置无动作/播放暂停/切换全屏，保存后行为一致。
- [ ] D05 右键拖动手势按设置执行，手势识别与普通右键菜单不冲突。
- [ ] D06 鼠标滚轮/侧键等只在明确配置并实现后显示对应提示；不保留无效的交互说明。
- [ ] D07 菜单打开、子菜单切换、弹出对话框期间，全屏自动隐藏计时暂停；关闭后重新计时。
- [ ] D08 画布、控制栏、队列侧栏、独立队列窗口之间鼠标进入/离开边界行为稳定。

### E. 全屏与窗口管理

- [ ] E01 双击视频画面默认播放/暂停；没有视频时打开文件选择器；可配置切换全屏或无动作。
- [ ] E02 全屏只显示视频画布；播放控制覆盖在画布底部，鼠标移动唤出、空闲超时隐藏；标题栏、菜单栏、状态栏和播放列表不占用全屏画面。
- [ ] E03 鼠标移入控制栏及其子控件时暂停隐藏计时，离开后恢复计时；控制栏底边唤出策略按最终交互设计一致实现。代码已修正控件子项之间移动时误启动隐藏计时的问题，并将状态栏纳入控制区；仍需运行验证。
- [ ] E04 退出全屏恢复原窗口大小、位置、最大化状态和侧栏偏好；窗口化播放控制栏也支持空闲自动隐藏。
- [ ] E05 多显示器间移动、全屏、拔插显示器后窗口不丢失到不可见区域。
- [ ] E06 置顶开关在菜单和设置面板之间同步，不意外丢失全屏/最大化状态。
- [ ] E07 多个播放器进程可独立运行、播放、关闭；一个窗口退出不影响另一个窗口。

### F. 字幕与视频轨道

- [ ] F01 可枚举、切换、禁用视频内嵌字幕轨道；当前轨道和默认轨道标记正确。
- [ ] F02 可加载/卸载外挂字幕；支持范围、编码失败和文件缺失有反馈。
- [ ] F03 同名外挂字幕自动匹配可配置；切换媒体不会残留上一媒体字幕。
- [ ] F04 字幕启用、样式、字号、颜色、位置和时间偏移的 UI 与实际渲染效果一致。
- [ ] F05 Seek、暂停、逐帧、切换轨道和切换媒体时字幕时间轴正确。
- [ ] F06 可枚举和切换视频文件中的音轨；不扩展音乐库或独立音频播放界面。
- [ ] F07 字幕/音轨列表在轨道数量为零、单条和多条时均显示合理状态。

### G. 画面调整、截图与信息

- [ ] G01 画面比例（原始、16:9、4:3）和拉伸策略切换立即生效，菜单/设置状态同步。
- [ ] G02 亮度、对比度、饱和度、色调、锐化、降噪、灰度有真实效果；组合顺序明确，重置有效。
- [ ] G03 旋转、SAR/DAR、画面缩放和窗口尺寸组合不发生拉伸错误。
- [ ] G04 截图支持配置的 PNG/JPEG/BMP，扩展名、编码格式和实际内容一致。
- [ ] G05 截图保存目录、文件名冲突处理、失败反馈和成功反馈正确。
- [ ] G06 播放信息窗口的媒体路径、容器、编码、分辨率、帧率、码率、像素格式、位深、SAR、旋转、色彩/HDR 元数据与探测结果一致。
- [ ] G07 信息缺失时显示“未知/不适用”，不伪造数据。

### H. 设置窗口与配置持久化

- [ ] H01 设置窗口包含常规、播放、界面、视频显示、画面滤镜、字幕加载、字幕样式、快捷键、截图、性能等页面；已采用左侧分类导航和右侧滚动页面，仍需 Windows 实机检查布局、焦点和缩放；每项设置都有实际行为。
- [ ] H11 播放设置中的循环模式、随机播放与播放列表按钮状态同步，重启后保持配置。

- [ ] H07 播放队列、最近播放、播放位置、书签、快捷键、窗口布局、截图配置和媒体偏好重启后正确恢复。

## 4. 必须执行的运行验收场景

每个场景记录 Windows 版本、显示缩放比例、显示器刷新率、视频样本信息、预期结果、实际结果和截图/日志。失败必须关联缺陷，不得标为通过。

1. 首次启动：无 Data 目录、无设置文件。
2. 便携目录：Data 可写，重启后设置仍存在。
3. 安装目录：程序目录不可写，自动回退到用户 Local App Data。
4. 配置迁移：旧版 INI 与旧注册表均存在，INI 已有值优先。
5. 打开单文件、多文件、文件夹和拖放导入。
6. 文件不存在、损坏文件、不支持编码、只有音轨无视频流。
7. 播放、暂停、停止、关闭、重新打开。
8. 连续快速 Seek、播放中 Seek、Seek 后立即暂停/切换媒体。
9. EOF 下普通播放、自动下一项开关、单项循环、列表循环。
10. 倍速切换、逐帧前进/后退、A-B 循环。
11. 队列多选、拖动排序、批量删除、删除当前项、清空。
12. 全屏进入/退出、控制栏自动隐藏、鼠标唤出、菜单停留、侧栏恢复。
13. 双击播放/暂停、中键全屏、空白画布拖动窗口、右键菜单、右键拖动手势。
14. 快捷键录入、重复冲突、前缀冲突、文本输入焦点和列表焦点。
15. 内嵌字幕、外挂 SRT、ASS/SSA、字幕延迟、样式、Seek 后同步。
16. 多音轨选择及音轨为空/单条/多条情况。
17. 画面比例、旋转、滤镜组合、灰度和重置。
18. PNG/JPEG/BMP 截图、目录不存在、文件重名和磁盘写入失败。
19. 播放信息窗口与实际探测元数据对照。
20. 多窗口独立播放和退出；关闭期间进行 Seek/解码请求。
21. 多显示器、高 DPI、不同刷新率、窗口最大化和置顶。
22. 安装、升级、默认应用选择、文件双击启动和卸载清理。
23. 长时间播放、频繁切换媒体、连续 Seek 后资源无持续增长或 UI 卡死。
24. 大目录扫描、批量媒体元数据探测、音乐库查询和外挂字幕回退解析期间，窗口仍可响应拖动、菜单和播放控制。
25. 视频帧 Pull 等待期间，播放/暂停/停止/Seek 命令不会被帧读取任务长期阻塞；同一 Player 命令顺序保持一致。
